# my-os lite

用 AI 帮你记住重要背景和日常经历，资料保存在你自己的 Markdown 文件里。

无需安装 Python，也无需注册额外服务。

## 第一次使用

1. 下载压缩包并解压到一个你打算长期保留的文件夹。如果来自 GitHub，请先下载 ZIP 并解压。
2. 在能读写本地文件的 AI 助手中打开这个文件夹，或把它添加为工作目录。只有网页浏览权限不足以保存到你的电脑。
3. 向 AI 发送下面这句话：

> 请读取这个文件夹的 AGENTS.md，带我开始使用 my-os。先帮助我录入基础信息，再把我愿意保存的信息写入本地文件。一次只问一个小问题，可以跳过；已有信息不要重复问。

AI 会先了解你希望怎样称呼、想记录哪些方面，以及必要的背景。不需要一次介绍完自己，也不需要提供真实姓名。

## 每天怎么用

直接说话即可，例如：

> 记一下：今天看了十页书，卡在第三章的一个概念。昨晚睡了七小时。

> 更正一下，刚才说的是昨天，不是今天。

> 最近不想记录睡眠了。

也可以说“看看最近的记录，帮我理一理”。不用每天打卡，不补造没记录的日子。

## 文件放在哪里

| 文件 | 用途 |
|---|---|
| AGENTS.md | AI 的统一操作规则 |
| PROFILE.md | 你愿意保存的背景、偏好和记录范围 |
| ACTIONS.md | 你明确接受的待办和重要决定；没有就留空 |
| records/ | 按月保存日常记录，如 2026-10.md，由 AI 创建 |

日常记录采用自然段和短列表，不要求固定表格。普通记录只写一次；背景改变时才更新 PROFILE，接受行动时才更新 ACTIONS。

## 保存、换 AI 与备份

- 每次实际保存后，AI 应告诉你保存到了哪个文件；你可以打开确认。
- 换 AI 时，重新打开同一个文件夹，让它先读 AGENTS.md。规则不会在所有聊天工具里自动加载。
- 只能聊天、不能改文件的 AI 可以整理文字，但你需要手动保存；它的回复不等于已经落盘。
- 定期复制整个文件夹备份。GitHub 是可选备份方式，不会自动同步本地文件；从网页下载的旧 ZIP 也不会自行更新。
- 上传你自己的记录时使用私人仓库，并检查本次上传文件。首次给别人分享时，只分享这份空白模板，勿打包自己的 PROFILE、ACTIONS、records 或附件。

这个入门包没有后台提醒、自动上传或自动统计。AI 的记忆也不能替代这些本地文件。

版本：lite 0.1。先使用、再按实际需要增加功能。
